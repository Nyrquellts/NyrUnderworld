# Artwork provenance

The street illustration was generated for this release in the built-in ImageGen
tool on 11 September 2026. Original output:
`exec-31868f16-89e0-4fd2-befa-fba6ca4e5aef.png`.

Brief: an original anonymous California industrial street at night, warm amber
lamps, charcoal shadows, restrained noir print texture and open space on the
left for NYR typography. No game screenshot, third-party logo or recognizable
franchise character was supplied. The local PNG is the generated output; it
is promotional illustration, not evidence of the game's appearance.

The 1280x720 and1080x1080 thumbnails were rendered from thumbnail.html over that
illustration. Typography is live HTML using local system fonts; no font files
are redistributed. Both thumbnails visibly identify promotional illustration.

The nine inline SVG symbols in adapter/nui/index.html were authored for this
resource: eight built-in item pictograms and one custom-item fallback. They
were not copied from an icon library or extracted from another game. They are
shared by inventory, stash and shop screens and covered by the resource licence.

Battle Brothers art, music and third-party mod files were not imported. Reused
Nyr work consists of the existing FiveM checks, bounded staging, evidence
discipline, shared handoff records and release validation infrastructure.
