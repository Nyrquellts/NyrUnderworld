Before you buy

Know what you’re getting.

Built for standalone servers

ESX, QBCore and QBOX bridges are not included or verified. Plan integration work if you already run another economy.

Six screens, plus commands

Characters, pockets, phone, shops, stashes and nearby places have interfaces. Actions such as starting work and banking use documented chat commands.

Your server, your setup

Requires FiveM, OneSync, a valid server license and a compatible GTA V client. Hosting and game copies are not included.

Evidence before promises

rc.4 passed 771 automated Lua tests on 12 September 2026. In-game visuals, multiplayer load and live database use still need verification.

What assets are included?

The resource includes its interface and simulation code. No custom maps, vehicles, clothing or streamed audio are included. The illustration on this page is promotional artwork.

Is support available?

A monitored support channel and the seller’s contact details must be completed before checkout opens. The release offer will describe its support scope and current compatibility.

Can I see it in game?

A verified gameplay demonstration is a release requirement. This local preview is for reviewing the interface and the proposed store presentation.
